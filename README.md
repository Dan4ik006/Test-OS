# NEXTGEN OS (hobby kernel)

Учебная 16/32-битная ОС для x86, запускаемая с дискеты/образа через BIOS.
Загрузчик переводит процессор в protected mode, настраивает пейджинг,
инициализирует VESA-режим 800x600x32 и передаёт управление ядру,
которое заливает экран цветом и рисует 24-битный BMP.

> Статус: **experimental / educational**. Не для реального использования.

## Что уже работает

- [x] Собственный boot sector (MBR, `org 0x7C00`) с ручной загрузкой секторов через `int 0x13`
- [x] Многоступенчатая загрузка: `setup` (0x4000), `GDT` (0x5000), `IDT` (0x2000), `kernel` (0x8000)
- [x] Переход в protected mode, загрузка GDT и IDT
- [x] Настройка страничной адресации (paging) для первых 4 МБ и видеопамяти (2 таблицы по 4 МБ)
- [x] VESA VBE: режим `0x144` (800x600x32, LFB)
- [x] Драйвер графики: `clear_screen`, `draw_pixel`, `draw_bmp` (24-bit BMP → 32-bit BGRA)
- [x] Заготовки: таблица IDT с обработчиками таймера и клавиатуры, константы клавиш (`keyboard.inc`)

## Что пока не работает / TODO

- [ ] Обработчики прерываний таймера и клавиатуры — только заглушки в IDT, кода нет
- [ ] Нет менеджера памяти, кучи, планировщика
- [ ] Нет файловой системы (образ читается посекторно с фиксированных адресов)
- [ ] `draw_bmp` не поддерживает прозрачность и масштабирование
- [ ] Загрузка ядра жёстко зашита на «10 секторов + 10 секторов» — при росте ядра надо править `boot.asm`

компиляция:
